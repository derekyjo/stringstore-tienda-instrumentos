# StringStore - Tienda de Instrumentos Musicales

Tienda online de instrumentos musicales desarrollada con HTML, CSS y JavaScript vanilla. Diseño moderno y minimalista con precios adaptados al mercado dominicano.

## Características

- 🎸 **Catálogo completo** - Guitarras, bajos, baterías, teclados y accesorios
- 🛒 **Carrito de compras** - Añadir, modificar cantidades y eliminar productos
- 🔍 **Búsqueda** - Filtra productos por nombre en tiempo real
- 🏷️ **Filtros por categoría** - Navega fácilmente por tipo de instrumento
- 💾 **Persistencia** - El carrito se guarda en localStorage
- 📱 **Responsive** - Se adapta perfectamente a móviles, tablets y desktop
- 💰 **Precios en RD$** - Formateados a Pesos Dominicanos
- ✨ **Diseño moderno** - Hero section, gradientes, animaciones y efectos hover

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, Animaciones, Gradientes)
- JavaScript Vanilla (ES6+)
- Font Awesome 6.4.0
- Google Fonts (Inter)

## Estructura del proyecto

```
tienda-instrumentos/
├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── data.js      # Catálogo de productos
│   └── app.js       # Lógica de la aplicación
└── README.md
```

## Cómo usarlo

1. Clona el repositorio o descarga los archivos
2. Abre `index.html` en tu navegador web
3. ¡Listo para comprar!

## Demo

Simplemente abre el archivo `index.html` directamente en tu navegador. No requiere servidor ni instalación de dependencias.

## Precios

Todos los precios están en **RD$ (Pesos Dominicanos)** y adaptados al mercado local.
